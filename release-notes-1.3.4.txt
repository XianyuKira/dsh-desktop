$notes = @"
修掉一个从**第一个版本**就存在、非常影响使用的缺陷：界面缩放。

## 修复：界面默认被缩到 20%

程序里缩放初值写成了 20，等于每次启动都把整个界面缩成 **0.2 倍**——字小到看不清，
状态栏右下角还一直显示"缩放 20%"。这是初值就写错了，之前只验证过"界面能渲染"，
没验证过"人看得清"。

现在：

- 默认 **100%**
- 范围 50%–300%（以前上限只有 200%）
- ``Ctrl+0`` 复位到 100%（以前是"复位到 20%"）
- ``Ctrl+=`` / ``Ctrl+-``、工具条 ＋ / － 照常可用

如果你在用旧版，装上这一版界面就正常大小了。

## 另外两个修复

**1. 首次运行向导此前不会出现。** 向导被绑在"是否随包分发"的判断上，所以普通安装
永远不会问 API Key 和数据目录。向导是"首次设置"，已与分发形态解绑。

**2. 端口冲突提示误导。** 以前只要输出里出现 ``EADDRINUSE`` 就笼统报"所有端口候选都失败了"，
于是插件固定端口（``dsh-mobile`` 的 3443）被占时，会去重试毫无帮助的 web 端口。
现在区分两种情况：只有冲突端口确实是本程序选的那个才重试；插件端口冲突会明确提示
**"已经有一个 dsh 在运行"**（关掉另一个再试即可）。

## 选哪个包

| 包 | 大小 | 适用 |
| --- | --- | --- |
| ``dsh-desktop-$version-win-x64.zip`` | 0.7 MB | **推荐**。需要 .NET 8 桌面运行时 |
| ``dsh-desktop-$version-win-x64-selfcontained.zip`` | 62 MB | 零依赖，已内嵌运行时 |

已经在用 1.2.0 及以上：菜单 →「检查更新」→「一键更新」即可，不用下载这两个包。

## 一键更新怎么工作

Windows 不允许覆盖正在运行的 exe，所以流程是：

``````
下载新包 → 启动更新助手 → 主程序退出（顺带关掉它托管的 dsh 服务）
        → 助手把新文件覆盖进原目录 → 自动重新打开程序
``````

**就地替换，同一个文件夹**，不会堆出新目录；你自己放进该目录的其它文件不会被删。
